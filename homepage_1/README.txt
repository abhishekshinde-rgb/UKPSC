UKPSC Homepage Redesign Concept — V2
====================================
Files:
- index.html — homepage structure and inline SVG icon library
- style.css — visual styling and responsive breakpoints
- script.js — mobile menu, notice filters/search, text-size and contrast controls

To preview:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use Live Server.

Notes:
- This is a design concept, not an official UKPSC website.
- The emblem is a placeholder, not an official state emblem.
- Notice content is sample layout content and must be checked against official notices before submission.
- Google Fonts are loaded online; fallback fonts are specified.
- The design is not a certification of GIGW/WCAG compliance. Validate the final implementation against applicable standards.
