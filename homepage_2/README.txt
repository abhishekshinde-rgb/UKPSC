UKPSC Homepage Redesign Concept — V3 (Interactive Full-Width Hero)
===================================================================
Files:
- index.html — homepage and inline SVG icon library
- style.css — styling, full-width hero banner, responsive breakpoints
- script.js — navigation, notice filters/search, accessibility controls and hero carousel

Preview:
1. Extract the ZIP.
2. Open index.html in Chrome or use VS Code Live Server.
3. Use the hero's previous/next arrows and dots to switch slides.
4. Use Pause/Play to control automatic rotation. The banner also pauses while hovered or focused.
5. Resize the browser to inspect tablet and mobile layouts.

Notes:
- Design concept only; not an official UKPSC website.
- Emblem is a placeholder, not an official government emblem.
- Sample notices must be verified against official UKPSC publications.
- Google Fonts require an internet connection; system fallbacks are included.
- Validate final implementation against GIGW/WCAG, security and performance requirements before production.
