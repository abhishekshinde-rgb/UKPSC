UKPSC Homepage Redesign Concept
================================

Files:
- index.html  : Homepage structure and sample content
- style.css   : Responsive styling
- script.js   : Menu, sample notice filtering/search, accessibility controls

How to view:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Resize the browser to review desktop, tablet and mobile layouts.

Important:
- This is a design concept/prototype, not an official UKPSC website.
- The emblem is a placeholder illustration, not an official government emblem.
- Notice examples are for layout demonstration. Verify titles, dates and details against official UKPSC publications before presenting the design.
- The page uses a Google Fonts import for DM Sans and Noto Sans Devanagari; local fallback fonts are specified.
- Before production, validate all links, accessibility, GIGW 3.0/WCAG requirements, security, content accuracy and performance.
